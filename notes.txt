The error missing value where TRUE/FALSE neded in BIOMOD_FormatingData is caused by passing an empty or invalid dataset to the function. This happened because the script was attempting to select the 3rd species (i=3), but your data file test_sp.txt only contains one species ("Agrostis capillaris").

Here is the breakdown of the issue:

i=3 was used, but sp.names only has 1 element.
sp.names[3] returned NA.
subset(spocc, ...) resulted in an empty dataset (or one with NAs).
spocc1[1:10000,] created a dataframe of 10,000 rows filled with NAs.
BIOMOD_FormatingData with na.rm=TRUE removed all these NA rows, leaving 0 presence points.
With 0 points, biomod2's internal checks for Pseudo-Absence strategy failed (likely due to undefined spatial ranges), causing the obscure error message.
I have fixed script_test.R by changing the index to i=1 to select the first (and only) species.

I also verified that test_sp.txt contains exactly 10,000 records for "Ag

rostis capillaris", so the subsetting spocc1[1:10000,] is safe.
