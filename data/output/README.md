# Output storage

Generated BIOMOD outputs are not kept in this local checkout.

The working copy is intentionally empty to save disk space. Scientific output is stored remotely:

- Leonardo source: `/leonardo_work/IscrC_SPECC/data/output/`
- Spartaco archive: `F:/HPC_Leonardo/`
- Production campaign on Leonardo: `/leonardo_work/IscrC_SPECC/data/output_campaign_pa10/`

Use `scripts/3sync.sh` to transfer output from Leonardo to Spartaco through Serviicola.
